# 🛡️ SecureNet Corp - AI-Powered Network Intrusion Detection System (NIDS)

## 📌 Project Overview
Developed as part of the Information Security CLO 4 assignment for **SecureNet Corp.** This project implements a machine learning-based Network Intrusion Detection System (NIDS) utilizing the **CIC-IDS2017 (DDoS-Friday)** dataset to detect and classify network traffic threats in real-time.

## 🚀 Key Features
* **Machine Learning Engine:** Built using a high-performance **Random Forest Classifier** achieving **99.98% accuracy**.
* **Interactive Dashboard:** Deployed via **Gradio** featuring a sleek custom **Purple & Blue** security theme.
* **Multi-Tab Interface:**
  * **Dashboard Overview:** Live system statistics and raw data inspection.
  * **Data Explorer:** Statistical summary of network features.
  * **Model Training:** Interactive hyperparameter tuning (test split ratio & number of decision trees).
  * **Visualizations:** Confusion Matrix heatmap for performance evaluation.
  * **Predictions:** Real-time incoming network packet threat simulation.
  * **Model History:** Audit trail of previous training runs.
